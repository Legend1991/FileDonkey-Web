Key Features
  • No cloud account, no subscription and no uploads — your files never leave your local network
  • Nothing to copy and nothing to sync — open a file straight from the other device and you have the current version
  • Works inside Finder, File Explorer and your Linux file manager — drag, drop, open and save exactly as usual
  • You choose the one folder each device shares; everything outside it stays invisible
  • Zero configuration — install it, and devices on the same network find each other on their own
  • Mac, Windows and Linux today, with Android and iPhone support planned
